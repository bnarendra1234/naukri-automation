1. Executive Summary

The Naukri Automation Bot is an enterprise-grade background automation engine engineered to maximize candidate visibility and streamline the job application process on Naukri.com.

Core Capabilities:

  • Profile Freshness Optimization: Recruiter search algorithms prioritize recently updated candidate profiles. The bot automatically touches the resume headline daily, tagging the account as "Updated Today" to increase recruiter impressions by 3–5x.
  • Automated Targeted Applications: Automatically searches for postings matching configured keywords, experience levels, and locations (including Remote), executing 1-Click Easy Apply while bypassing dead-end third-party redirects.
  • Deduplication Database: Persists applied job IDs and metadata in a structured JSON database to ensure no job is ever applied to more than once.
  • Anti-Detection & Human Mimicking: Utilizes Playwright Chromium stealth modifications, randomized typing cadences, and realistic mouse movements to safeguard candidate accounts.

4. Core Services & Implementation Details

4.1 BrowserManager (Browser Lifecycle & Anti-Detection)

Located at com.naukri.automation.browser.BrowserManager. Configures Chromium with anti-bot evasion arguments:

  • --disable-blink-features=AutomationControlled: Removes automated browser flag.
  • Injects navigator.webdriver = undefined into the context before script evaluation.
  • Saves browser session state (cookies, local storage) into data/session_state.json for seamless future logins.

4.2 AuthService (Authentication & OTP Handling)

Located at com.naukri.automation.service.AuthService. Checks session status via /mnjuser/profile. If expired, authenticates at /nlogin/login using randomized human keystroke pacing (60ms). If an OTP challenge is triggered, pauses for 60s in visible mode (HEADLESS=false) to allow the user to complete verification once.

4.3 ProfileService (Profile Booster)

Located at com.naukri.automation.service.ProfileService. Navigates to the user's Naukri profile, edits the Resume Headline textarea, toggles a trailing period (.), and clicks Save. This simple operation refreshes the timestamp on Naukri's indexer, placing the candidate profile in the top tier of recruiter candidate searches.

4.4 JobSearchService & ApplierService

JobSearchService builds structured query URLs and extracts job cards via DOM locators. ApplierService verifies that the job does not belong to an excluded company or title keyword, checks deduplication history, clicks Apply, and dismisses questionnaire dialogues.

6. Execution & Deployment Strategies

Option 1: Windows Task Scheduler (Recommended for Local PC)

Run PowerShell as Administrator and execute:
powershell -ExecutionPolicy Bypass -File setup_windows_task.ps1

This registers a task named NaukriDailyJobApply that triggers run_daily.bat automatically every morning at 8:30 AM IST.

Option 2: Cloud Automation via GitHub Actions (100% Free Serverless)

1. Push this repository to a Private GitHub repository.
2. In GitHub, go to Settings > Secrets and variables > Actions.
3. Add NAUKRI_EMAIL and NAUKRI_PASSWORD.
4. The pre-configured workflow at .github/workflows/daily_naukri.yml runs every morning at 8:30 AM IST (03:00 AM UTC).

Option 3: Manual CLI Execution

# Run once immediately
java -jar target/naukri-automation.jar

# Run immediate test + start daily 8:30 AM scheduler daemon
java -jar target/naukri-automation.jar --run-now
