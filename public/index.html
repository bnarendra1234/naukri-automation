🚀 Core Automation Features

1
Daily Recruiter Visibility Booster

Touches the resume headline daily, putting your profile at the top of recruiter searches with an "Updated Today" badge.

2
1-Click Easy Apply Execution

Automates job discovery, filters out third-party external redirects, and submits standard questionnaire modals.

3
Local JSON Deduplication DB

Maintains history in data/applied_jobs.json so you never apply to the same position twice.

4
Stealth Anti-Detection Engine

Emulates human mouse movements, randomized keystroke delays, and preserves session cookies in data/session_state.json.

⚡ Quick Commands

Run directly using the pre-compiled fat JAR:

# 1. Build Fat JAR
mvn clean package -DskipTests

# 2. Run once immediately
java -jar target/naukri-automation.jar

# 3. Start 8:30 AM IST Scheduler Daemon
java -jar target/naukri-automation.jar --run-now

⚙️ Execution Methods

Option A: GitHub Actions (Free Cloud)

Runs serverless in the cloud daily at 8:30 AM IST via .github/workflows/daily_naukri.yml.

Option B: Windows Task Scheduler

Run setup_windows_task.ps1 as Admin to register a Windows background task.

Option C: Local Batch Runner

Double-click run_daily.bat anytime for an immediate test.
